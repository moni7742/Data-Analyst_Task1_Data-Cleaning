
# Data Analyst Task 1 – Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing the Customer Personality Analysis dataset using Python and Pandas.

The objective is to identify and handle missing values, remove duplicate records, standardize text values, convert date formats and check data quality.

## Dataset
- Dataset Name: Customer Personality Analysis
- Source: Kaggle
- Original File: marketing_campaign.csv
- Records: Approximately 2,240
- Columns: 29

## Tools and Technologies
- Python
- Pandas
- NumPy
- VS Code

## Data Cleaning Steps
1. Loaded the original dataset.
2. Checked missing values.
3. Identified and removed duplicate records.
4. Standardized text values.
5. Renamed column headers.
6. Handled missing Income values using median.
7. Converted customer enrollment dates into datetime format.
8. Checked data types.
9. Identified potential outliers using IQR.
10. Exported the cleaned dataset.

## Project Structure
- dataset/ – Original dataset
- output/ – Cleaned dataset and summary report
- data_cleaning.py – Python cleaning script
- requirements.txt – Required libraries

## Output
- cleaned_customer_data.csv
- cleaning_summary.txt

## Conclusion
The dataset was cleaned and preprocessed using Python and Pandas. Missing values were handled, duplicate records were removed, text formats were standardized and date formats were converted.

The final dataset is structured and ready for further data analysis and visualization.
